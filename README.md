# Briano's Website

The website for Briano's, a shisanyama, bar and lounge in Soshanguve. Built with Vite, React, TypeScript, Tailwind CSS and shadcn/ui.

## Run it

```sh
npm install
npm run dev
```

## Update the content

Prices, the menu, opening hours, the weekly line-up, specials, FAQs, the business name and contact details all live in `src/data/brianos.ts`. The page title and social preview text are in `index.html`. Photos and logos are in `public/images/brianos/`.
